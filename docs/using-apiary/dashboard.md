# Dashboard

The Dashboard is the first page you see when you open Apiary. It answers two questions: what has my team done, and what needs me?

- **Top row:** tasks finished (compared with the same number of days before), agents working right now, approvals waiting for your answer, and anything that needs attention such as an offline device. Each tile opens the page behind it.
- **Tasks finished per day:** a bar for each day. Use the box at the top right to look at the last 7, 14 or 28 days.
- **What your agents did:** the latest finished, stuck and running tasks. Click one to open it.
- **Needs you:** approvals to answer, devices that cannot be reached (with a **Troubleshoot** button), and health warnings.
- **AI usage this week:** how much of your weekly limit each AI has used. Set the limits on the Usage page.
- **Projects:** how many tasks are done in each active project.

The page updates by itself while agents work. Chat is still one click away under **Open chat** or in the menu.
