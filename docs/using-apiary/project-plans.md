# Project plans and progress

Big projects are done in phases. For anything large, the lead agent first writes a plan: a goal and a list of phases, each with steps. The plan is shown to you as an approval. Nothing starts until you approve it.

## What you see
- A **Plan** tab on the project with each phase, its steps and ticks as steps are finished.
- A progress bar and **% done** on the project card and in the project header.
- The current phase is highlighted. When all steps in a phase are done, the next phase starts by itself.

## Changing the plan
You can edit the plan at any time on the Plan tab, ask the lead to draft a new one, or clear it. Agents report progress as they work, and the plan is part of what every agent in the project is told.
