# Tasks

The **Tasks** page is a board with five columns:

| Column | Meaning |
|---|---|
| To do | Will be done soon |
| Back burner | An idea that is not finished. You will add more detail later |
| In progress | Someone is working on it |
| Blocked | Stuck. It needs a decision or something is missing |
| Done | Finished |

Add your own tasks at the top: choose **To do** for work you want done soon, or **Back burner** for an idea. Give a task labels (for example `website`, `money`) to find it later. Use the menu on a card to move it, or **Edit** to change the details and see its history.

Agents use the board too. When your CEO hands a job to a team member, a task appears as *In progress*, then moves to *Done* (or *Blocked* if the job could not start). Support tickets show up here as well.
