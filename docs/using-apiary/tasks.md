# Tasks

The **Tasks** page is a board with five columns:

| Column | Meaning |
|---|---|
| Back burner | An unfinished idea. You will add more detail later |
| To do | Ready: the work is described and can start |
| In progress | Someone is working on it |
| Blocked | Stuck. It needs a decision or something is missing |
| Done | Finished |

Add your own tasks at the top: choose **Back burner** for an unfinished idea, or **To do** for work that is ready to start. Give a task labels (for example `website`, `money`) to find it later. Use the menu on a card to move it, or **Edit** to change the details and see its history.

Agents use the board too. When your CEO hands a job to a team member, a task appears as *In progress*, then moves to *Done* (or *Blocked* if the job could not start). Support tickets show up here as well.
