# Live activity

**Live activity** (open it from **See live activity** in the Working now box in the menu) shows every agent that is working right now: your CEO, specialists and project helpers. Each card shows what the agent is doing, its latest terminal output, and buttons to **Open chat** or **Stop**. It updates by itself.

The sidebar also has a **Working now** box with the same agents. Click one to open it.

On the [Tasks](tasks.md) board, a task whose agent is working (or whose agent has handed the work to a specialist) shows a live line with a **Watch** button that opens that agent's chat.
