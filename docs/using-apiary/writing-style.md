# Writing style and handover notes

Both settings are on **Settings, Appearance**, in their own cards.

## Writing style: plain, simple English

**Agents write in plain, simple English** is **on by default**. Agents then use short sentences and everyday words, and break long answers into short paragraphs and lists. Reports and approval briefs avoid technical terms, file paths and code unless you need them. Bold and lists are shown properly in chat instead of as raw symbols.

Turn it off if you prefer technical language. The change applies to agents' next answers.

## Handover notes

**Agents keep a short handover note for multi-step work** is on by default. If Claude and Codex swap because one hit its limit, the other reads the note and carries on. See [Keep going when an AI runs out](continuity.md).
