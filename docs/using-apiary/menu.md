# The menu

The menu on the left is a tree. Each heading opens to show its pages and, where there are many, folders that open the same way. A number on a heading or folder (approvals waiting, runbooks to review, health warnings) shows even when it is closed.

- **Workspace:** Chat, Projects, Tasks, Approvals, Support tickets, Terminal sessions. Folder *Plan and reuse*: Project templates, Runbooks, Weekly report.
- **Agents:** All agents, Organisation, Team meetings. Folder *Library*: Teams, Saved agents, Delegation rules. Folder *Knowledge*: Memory, Repositories.
- **Infrastructure:** Devices, Library, Map, Health.
- **Connections:** Overview, Usage. Folder *AI tools*: Claude Code, Codex. Folder *GitHub*: Connection, GitHub repository map.
- **Security:** Sign-in, Secrets vault, Approval rules, Access and safety, Audit log.
- **Settings:** Appearance, Telegram alerts, Setup guide. Folder *Data*: Backups, Export and import, Factory reset. Folder *System*: Updates, Startup, Folders.

Every page and folder has a small icon. The page you are on is always opened for you, and The **Documentation** link is at the top of the window. The search box at the top (Ctrl+K) finds things without using the menu.

## On a phone

Apiary works in a phone browser. Tap the menu button (top left) to open the menu; tap outside it to close it. The search is the magnifier at the top. In a project, tap **Details** to show the stage, owner and action buttons. Wide things such as tables, the task columns and the map swipe sideways. To open Apiary from your phone, see [Using it beyond your own computer](../reference/security.md) (use a VPN or SSH tunnel, not the open internet).

**Dashboard** is the first item, above the groups. **Library** sits under Infrastructure.

Live activity is not in the menu: open it from **See live activity** in the Working now box at the bottom of the menu.
