# The menu

The menu on the left is a tree. Each heading opens to show its pages and, where there are many, folders that open the same way. A number on a heading or folder (approvals waiting, runbooks to review, health warnings) shows even when it is closed.

- **Workspace:** Chat, Live activity, Projects, Tasks, Approvals, Support tickets, Terminal sessions. Folder *Plan and reuse*: Project templates, Runbooks, Weekly report.
- **Agents:** All agents, Organisation, Team meetings. Folder *Library*: Teams, Saved agents, Delegation rules. Folder *Knowledge*: Memory, Repositories.
- **Infrastructure:** Devices, Map, Health.
- **Connections:** Overview, Usage, GitHub. Folder *AI tools*: Claude Code, Codex.
- **Security:** Sign-in, Secrets vault, Approval rules, Access and safety, Audit log.
- **Settings:** Appearance, Telegram alerts, Setup guide. Folder *Data*: Backups, Export and import, Factory reset. Folder *System*: Updates, Startup, Folders.

The page you are on is always opened for you, and the path above the page (for example Settings / Data / Backups) follows the menu. The search box at the top (Ctrl+K) finds things without using the menu.
