# Project stages

Every project is in one of three stages. The stage shows on the project card and in the project header, and you can change it at any time with the **Stage** dropdown.

| Stage | Meaning |
| --- | --- |
| **Building** | Being made for the first time. New projects start here. |
| **Maintenance** | Finished. Only fixes, security updates and small changes. The lead is told this, so it does not start big new work without asking you. |
| **Closed** | Finished for good. Everything is kept, but no agent works on it and it is left out of team meetings. |

The Projects page groups projects by stage. Closed projects are folded away under **Closed**.

## Moves
- When the last phase of a project plan is done, a project that is being built moves to **Maintenance** by itself. You can move it back.
- Closing a project stops anything that is running. **Nothing is ever deleted.** Chats, files, plan, memory and tasks stay, and you can reopen the project at any time.
- Every move is written to the project's history (who, when, and a note).

If you really want a project gone, the **Delete** button is still there. Closing is the safe choice.
