# Call an agent with @

In any chat, type **@** and a list of people you can call appears. Pick one (arrow keys and Enter, or click), write what you want, and send.

```
Please @Maya Quill check the new landing page
```

## What happens

1. Your message is shown in the chat you are in.
2. A small note says **Sent to Maya Quill**.
3. Maya receives your message in **her own chat**, without the `@`, and starts working.
4. When she answers, the answer appears in the chat you are in, under her name. It is also in her own chat.

The agent whose chat you are in is **not** asked, because you called someone else. You can tag more than one person (`@Maya and @Luca introduce yourselves`). Each gets the message and each answer appears when it is ready.

## Who can you call?

* Everyone in the team of the chat you are in.
* Your CEO.
* The lead of every open project.

Agents in a **closed** project cannot be called. Reopen the project first (see [Project stages](project-stages.md)).

## Details

* Names can have spaces (`@Captain Atlas`) and capitals do not matter. Job titles work too (`@CTO`).
* `@` inside an e-mail address or in the middle of a word is ignored.
* A tag with nothing to do (`@Maya` and nothing else) is refused, and your text stays in the box so you can finish it.
* A name that is not on the list is treated as normal text, and the message goes to the agent whose chat you are in.
* Two agents with exactly the same name cannot be called by name. Rename one of them.
* Agents can already message each other while they work. Tags are for **you**.
