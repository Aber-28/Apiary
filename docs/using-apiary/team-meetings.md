# Team meetings

Agents can meet regularly so everyone knows what changed.

- Choose **Never**, **Every day** or **Every week**, and a time (midnight works well), under Agents → Team meetings or in the wizard.
- In a meeting every agent reports what it did, then reacts to the others' updates.
- Minutes are saved as Markdown in `~/.apiary/meetings/` and added to each agent's memory.
- **Hold a meeting now** runs one immediately.

Apiary must be running at the scheduled time.
